   - High-converting multi-step lead capture modals & consultation booking

## 🛠️ Tech Stack

- **Framework:** React 18 (Vite 5)
- **Styling:** Tailwind CSS 3.4, PostCSS, Autoprefixer
- **Motion & 3D:** GSAP 3.12, @gsap/react, Framer Motion, Three.js
- **Icons:** Lucide React
- **SEO & Meta:** React Helmet Async
- **Routing:** React Router DOM 6

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Development Server
```bash
npm run dev
```
Runs locally on `http://localhost:5173/`

### 3. Production Build
```bash
npm run build
```
Generates production assets in `dist/`

### 4. Preview Build
```bash
npm run preview
```
Previews production build on `http://localhost:4173/`
